# Sprint 02 — design system and global shell

## Included

- Comfortaa display typography and Inter body typography from local, self-hosted assets.
- Warm off-white, ink, olive, and terracotta design tokens.
- Responsive global header, fullscreen menu, wordmark, editorial action links, and active-route treatment.
- Lenis smooth scrolling disabled automatically for reduced-motion users.
- Responsive curtain footer whose spacing is measured by `ResizeObserver`; no fixed 800 px assumption.
- Keyboard-reachable navigation, semantic landmarks, visible text labels, and animation-independent content.
- A restrained foundation preview page. Full accommodation page composition remains Sprint 03 scope.
